# V11-04 · 草稿箱、预览、原地编辑与保存

**前置：** V11-03。

**结果：** AI 结果不会丢失，老师可以在同一区域查看、编辑、重新生成，并确认保存到课次。

## 最小范围

- 生成完成立即保存为课次关联的 `draft`，不要求 student；保留现有 V1 note/草稿数据且迁移不得破坏内容。
- 全局“备课”入口显示草稿箱，列出未保存草稿的课程、课次、类型和修改时间。
- 当前课次左侧只列该课次的生成结果；点击一项后右侧只显示该内容。
- 右侧同一个内容容器在 Preview 与 Editor 间切换；不得同时渲染两个正文副本或跳转到新页面。
- “保存修改”更新同一草稿并回到预览；“取消编辑”丢弃本次未保存的 UI 修改。
- “保存到当前课次”把同一记录从 `draft` 改为 `saved`，不复制正文；保存结果可从课次重新打开。
- “重新生成”创建新草稿，旧草稿保留；存在未保存编辑时做简单确认。
- 支持软删除不需要的草稿；不实现版本树、审批流、审计日志或复杂恢复状态机。

## 验证

- 生成后退出并重开，草稿仍在草稿箱；保存到课次后从草稿箱消失并可在课次中查看。
- Preview → Editor → 保存修改 → Preview 始终使用同一区域并显示最新正文。
- 重新生成不覆盖旧草稿、已保存成果或老师原资料。
- 运行相关测试、typecheck、lint。
