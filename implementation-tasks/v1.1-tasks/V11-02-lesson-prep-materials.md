# V11-02 · 课次备课入口与本次资料

**前置：** V11-01。

**结果：** 老师从某个课次直接开始备课，并把外部资料或素材复制成该课次的独立资料。

## 最小范围

- 主流程改为“我的课程 → 课次 → 开始备课”，页面自动携带课程/课次上下文。
- AI 备课以 lesson 为必需上下文，不再要求先选择 student；一对一可自动显示关联学生，班课允许无单个学生。
- 左侧显示“本次备课资料”，提供“从外部资料添加”和“从素材库添加”。
- 外部资料页在课次上下文中显示“用于本次备课”；无课次上下文时显示“复制到素材库”。
- 两种加入操作都复用 managed 临时写入、校验、原子重命名和课次链接，生成真正独立副本。
- 新加入资料默认选中用于本次生成；选择 UI 可保持为页面状态，课次 managed 文件关系必须持久化。
- 不新增备课 session、Workflow 或通用状态机。

## 验证

- 从课次进入备课，分别加入一份外部资料和一份素材，返回后两份都出现在本次资料中。
- 修改课次副本不影响外部原件或素材；复制失败不留下正式半文件。
- 班课无学生时仍可进入备课；一对一可显示已有学生上下文。
- 运行相关测试、typecheck、lint，并完成一次简短人工 UI 体验。
