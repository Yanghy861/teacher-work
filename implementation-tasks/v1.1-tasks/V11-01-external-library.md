# V11-01 · 外部资料浏览

**前置：** `checkpoint-L12-pass`。

**结果：** 老师可以登记一个真实资料目录，在工作台中安全、按需地浏览文件夹和文件。

## 最小范围

- 增加一个 external root 的设置、持久化和更换入口。
- Main 提供类型化目录浏览能力；Renderer 只使用 root ID 与相对路径。
- 文件夹按展开 lazy 读取；支持手动刷新、打开文件、在资源管理器显示。
- 实现“全局导航｜可折叠资料树｜内容区”，树折叠后内容区扩展。
- 文件内容区显示名称、类型、大小、修改时间和可用操作；不要求 Office/PDF 高保真预览。
- 每次操作校验真实目标仍在根目录内，拒绝相对路径穿越、链接/联接逃逸和未登记路径。
- 不实现 watcher、递归扫描、搜索、多 root、删除、移动或重命名外部文件。

## 验证

- 设置目录，lazy 展开多层中文目录，选择文件并打开/显示位置，折叠和恢复资料树。
- Windows 中新增文件后手动刷新可见。
- 路径穿越、根外链接目标和 Renderer 任意绝对路径请求被拒绝。
- 运行相关测试、typecheck、lint。
