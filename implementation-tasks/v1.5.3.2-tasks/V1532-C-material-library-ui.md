# V1532-C · 素材库树形工作台与资料流转 UI

**状态：** 待产品负责人确认，不进入当前活动链

**前置：** V1532-B `DONE`；素材库目录 IPC 契约稳定。

## 目标

让素材库在 Renderer 中呈现为老师自己维护的逻辑目录树，交互参考外部资料的展开/收起体验，但不复用外部资料的真实目录事实。

## 页面结构

左侧：

- 全部素材；
- 最近使用；
- 待整理；
- 老师自建文件夹树；
- 展开/收起、选中态和同级顺序。

右侧：

- 逻辑面包屑，如 `素材库 / 七年级 / 三角形`；
- 当前目录文件列表；
- 文件详情和来源；
- 打开、所在文件夹、移动到、复制到课次、移除；
- 新建文件夹、导入资料。

类型只放在辅助筛选区：`文档 / 图片 / 其他`，不得替代老师目录树。

## 交互要求

- 目录按需展开，不一次性把整个素材库强制展开；
- 新建文件夹默认创建在当前选中目录；
- 重命名和删除使用明确按钮或菜单，不依赖右键作为唯一入口；
- 删除非空目录时显示原因并保留当前页面状态；
- 文件移动使用目标目录选择器，不要求首版拖拽；
- 空状态区分“没有素材”和“当前目录为空”；
- 搜索结果必须显示逻辑路径；
- 从课程备课入口进入素材库时，目标课次显示在页面上下文中；
- `复制到课次` 必须显示完整目标，不使用含糊的“当前课次”作为唯一提示；
- 课次资料区的 `从本课移除`、素材库的 `保存为素材` 和外部资料的 `保存到素材库` 三条路径文案必须方向一致。

## 响应式与可访问性

- 宽屏使用“逻辑目录树 + 文件区”两栏；
- 窄屏目录树折叠到文件区上方，不产生页面级横向溢出；
- 目录按钮、文件操作和目标选择器可键盘聚焦；
- 当前目录、选中文件和展开状态具有可读的 aria 状态；
- 文件名过长时截断但保留完整 title/详情，不撑破布局。

## 不做

- 不把素材库做成外部资料的镜像；
- 不自动按年级、教材或 MIME 类型建目录；
- 不新增独立课件库、第二棵课程树或多文件版本组；
- 不增加拖拽整理、云同步、批量入课和自动推荐。

## 验收

- 新建“七年级 / 三角形”并导入资料，列表和面包屑显示正确；
- 移动、重命名、删除空目录后刷新/重启仍正确；
- 搜索结果显示逻辑路径，类型筛选只影响结果不改变目录；
- 从素材库复制到指定课次，课次出现独立副本，素材库原件保持不变；
- 从外部资料保存到指定目录，外部原文件保持不变；
- 课次移除副本后素材库原件仍可打开；
- 1200px 和窄窗口代表性流程无横向溢出。
