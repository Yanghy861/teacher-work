# V1532-B · 素材库目录服务与安全 IPC

**状态：** 待产品负责人确认，不进入当前活动链

**前置：** V1532-A `DONE`；目录模型和迁移规则已冻结。

## 目标

在既有 Electron Main / Preload / Renderer 边界内提供素材库逻辑目录的最小管理能力。Renderer 只使用类型化白名单 IPC，不直接访问 SQLite、Node 或任意文件系统。

## 范围

提供以下能力，名称以最终契约为准：

- 查询素材库目录树和当前目录文件；
- 创建子文件夹；
- 重命名文件夹；
- 移动素材到指定文件夹或“待整理”；
- 删除空文件夹；
- 调整同级排序；
- 将外部资料复制到指定素材库文件夹；
- 将课次资料复制为新的素材库原件；
- 查询素材的逻辑路径，供详情和搜索结果展示；
- 复制素材到明确选择的课程/阶段/课次。

## 服务边界

- 目录事务只更新目录表，不修改 managed 对象路径；
- 文件复制继续复用 `ManagedFileService` 的原子复制、路径边界和失败清理；
- 外部资料复制继续复用 external root 校验，外部原件保持只读；
- 课程副本与素材库原件继续使用独立对象；
- 删除目录不级联删除文件；
- 文件软删除后不再出现在活动目录，但保留可审计的删除记录；
- 目录查询不得隐式改变 Current Lesson 或任何课程进度事实。

## IPC 安全要求

- 所有请求和响应增加运行时守卫；
- 目录 ID、文件 ID、名称、父目录和排序值在 Main 侧二次校验；
- 拒绝跨工作区 ID、越界路径、空名称、目录自挂载和移动到自身后代；
- 删除非空目录返回可理解的业务错误；
- 不把真实路径、API Key 或文件正文写入日志；
- 未登记或已删除文件不能被复制、打开或移动到活动目录；
- 复制失败不得留下正式 managed 半文件或数据库孤儿记录。

## 文案契约

- 外部资料 → 素材库：`保存到素材库`；
- 素材库 → 课次：`复制到课次`；
- 课次 → 素材库：`保存为素材`；
- 不再使用没有明确目标的 `加入当前课次` 作为全局素材库动作；
- 从某节课上下文进入时可显示 `用于本课`，但必须同时显示完整课程/阶段/课次名称。

## 不做

- 不增加拖拽作为唯一操作入口；
- 不增加批量移动、批量组卷、推荐或云端同步；
- 不让 Renderer 读取实际 managed 文件路径；
- 不新增独立素材搜索服务，先复用现有 Search 能力或目录内查询。

## 验收

- 契约测试覆盖正常请求、无效 ID、目录自挂载、非空目录删除、重复排序和复制失败；
- Preload 暴露面只有白名单方法，未泄漏 Node/SQLite 能力；
- 外部原件、素材库原件、课次副本三者修改互不传播；
- 重启后通过 IPC 重新读取到相同目录树和逻辑路径。
