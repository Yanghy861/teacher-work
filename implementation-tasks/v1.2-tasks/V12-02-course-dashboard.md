# V12-02 · 我的课程、软推进与点名交互

**前置：** V12-01 `DONE` 及其 CoreOverview、课程进度与点名 IPC。

**结果：** 老师在课程列表/详情中看清 Current Lesson、Viewed Lesson、今日待点名和实际教学状态，并以明确确认完成软推进。

## 最小范围

- 重构为“全局导航｜课程列表｜课程详情”，提供搜索、活动/已结束筛选、全局待处理草稿统计入口。
- 今日待点名只读取本地今天、未结束课程的 scheduled lesson；点名后显示统计，无学生时禁用保存。
- 创建课程使用 Modal；空课程引导创建第一阶段/第一课；第一课可初始化 Current Lesson。
- 课程详情只保留课次、学生、资料；阶段/课次用局部 Modal，阶段内稳定显示“第 N 课”。
- Current Lesson 与 Viewed Lesson 分离；点击课次只查看，开始备课不推进。
- 确认本课已上 Modal 展示默认建议，可改选有效课次或清空；重复确认展示已确认结果。
- 阶段边界提供开始下一阶段、选择其他课次、暂不继续、结束课程；已结束课程可重新开启。
- 课次支持 UTC 时间编辑与点名/修改点名 Modal；点名和确认已上互不触发。

## 验证

- Current 第 8 课确认后可接受同阶段第 9 课建议；确认非 Current 第 10 课保持第 8 课。
- 第 9 课可先于第 8 课点名/确认，之后补录第 8 课，记录互不覆盖。
- 重复确认不改变时间和 Current；阶段末不跨阶段；暂停/结束/重开关闭应用后仍保持。
- 本地午夜边界的今日待点名归属正确；名单变化时旧弹窗保存被拒绝。
- 运行 V12-02 相关测试、typecheck、lint，并完成代表性本地 UI smoke。
