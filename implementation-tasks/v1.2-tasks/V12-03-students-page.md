# V12-03 · 真正的学生页

**前置：** V12-02 `DONE`，课程列表/详情导航目标与课程学生关系语义稳定。

**结果：** “学生”成为学生列表和学生详情入口，只展示长期课程关系与人工学习记录。

## 最小范围

- 建立 StudentsPage：学生列表、姓名搜索、新建学生。
- 列表只显示姓名、当前在读课程和最近一条 manual 学习记录。
- 学生详情纵向显示在读课程、已退出/已结束历史课程与最近 manual 学习记录。
- 课程行可跳转到唯一课程详情；课程学生区可跳转到学生详情，App 只提升导航目标 ID。
- 新增人工记录只填写正文和可选关联课次；Service 验证该课次所属课程与学生存在当前或历史关系。
- 明确过滤 lecture/example/homework；不显示学生文件、附件、成绩、画像或文件统计。

## 验证

- 新建、搜索和打开学生；退出/重新加入后正确分入在读/历史课程。
- 只显示 manual 记录；非法关联无关系课次被 Main/Service 拒绝。
- 双向课程/学生跳转复用同一详情，不复制页面。
- 运行 V12-03 相关测试、typecheck、lint，并完成代表性本地 UI smoke。
