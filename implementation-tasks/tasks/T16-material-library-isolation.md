# T16 · 自由素材库与课次副本隔离

**前置：** T11、T12、T15。  
**目标：** 实现自由组织的托管素材，并证明资料加入不同课次后完全独立。

## 实现范围

- 素材库允许 folder/reusable_unit 的自由树和 managed 文件导入；不强制年级/教材/知识点分类；
- 实现“加入当前课次”：为每次操作创建全新 file ID 与物理副本，设置 `origin_file_id`；
- 实现“从实际课保存到素材库”，同样创建独立副本；
- 复制失败时不得创建半记录；删除课次副本不影响来源素材；
- Service 返回清晰来源信息供 UI 展示，但不做同步、更新传播或二进制去重；
- 加入 A 班、B 班的同一素材必须得到三个相互独立的对象。

## 不做

标签、收藏、继承、自动同步、写时复制、去重、版本合并。

## 验收

- 覆盖原规格测试 4–6：复制得到独立文件，修改 A 班不改变素材 Hash，也不改变 B 班；
- 反向修改素材或 B 班同样不传播；
- origin 记录可追溯但删除 origin 不使副本失效；
- 大文件复制失败/取消遵守 T15 的原子性。
