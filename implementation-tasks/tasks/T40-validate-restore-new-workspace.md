# T40 · 备份校验与恢复到新工作区

**前置：** T39、T31、T02。  
**目标：** 安全地把备份恢复到新的/空工作区，验证后才允许切换，绝不覆盖当前工作区。

## 实现范围

- `validateBackup` 检查包格式、manifest、schemaVersion、workspaceId、SQLite 可打开/integrity、托管目录结构与关键文件可访问；
- 解包防路径穿越、绝对路径、符号链接/reparse point 逃逸、压缩炸弹式异常大小；
- `restoreBackup` 只接受新建或明确为空目录；先恢复到 staging，完成 Migration 与验证后再发布；
- 恢复后不带 search.db，自动进入可见的重新索引流程，已索引部分可先搜索；
- external roots 保留元数据，原路径失效时提示逐 root 重定位；
- API Key 状态必须为未配置，由老师重新设置；
- 当前工作区只有在新工作区验证通过且老师确认后才切换。

## 不做

原地覆盖恢复、合并两个工作区、跨版本任意降级、恢复 external 原件。

## 验收

- 空工作区恢复后课程、学生、links、素材、managed 文件、AI notes 一致；
- 当前工作区在任何失败点完全不变；
- 恶意/损坏/版本不支持的包被安全拒绝；
- 覆盖原规格测试 15、27，且 Key 需重新配置、搜索重新生成。
