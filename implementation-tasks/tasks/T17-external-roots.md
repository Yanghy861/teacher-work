# T17 · external roots、扫描、missing 与重定位

**前置：** T14、T15、T08。  
**目标：** 只读接入老师已有资料目录，支持整体迁移和单文件缺失，而不接管原件。

## 实现范围

- ExternalRootRepository/Service 实现注册、启停、后台扫描、重新扫描、重定位；
- 设置页提供最小 root 管理 UI：添加、启停、扫描进度、错误、重定位；
- 文件记录只保存 root ID + 相对路径；扫描不得修改、移动或删除外部原件；
- 扫描大目录时 Main/Renderer 保持可操作，并可报告进度、单项错误和取消；
- 文件消失时标 `missing` 而不是删除记录；重新出现或人工重新定位后恢复 available；
- 整体 root 从 D 盘迁到 E 盘时只更新 root path，已有相对路径记录不批量改写；
- 处理无权限、循环符号链接/reparse point、大小写、长路径和扫描中变化；
- “加入课次”调用 T15 创建 managed 副本，绝不直接编辑 external 原件。
- 工作台自身绝不写 external 原件；打开原件时清楚标为只读参考，并优先使用不会改写的查看方式，无法强制第三方应用只读时要提示老师先复制到课次再编辑。

## 不做

不做 OS 级持久 File ID 跟踪、不备份 external 原件、不为扫描 PDF 做 OCR。

## 验收

- 覆盖原规格测试 8、9；
- root 重定位后既有文件 ID 不变且路径可解析；
- missing 文件记录和搜索来源元数据仍保留；
- 扫描测试证明不会越过选定根目录或跟随循环逃逸。
