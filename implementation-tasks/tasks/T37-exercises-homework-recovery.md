# T37 · 例题、作业、重试与步骤恢复

**前置：** T36。  
**目标：** 完成 V1 固定备课链路，并证明只重做失败步骤。

## 实现范围

- 在人工确认/修改讲义后分别生成例题、作业；每步使用明确、版本化 prompt；
- 每个完成结果立即保存为当前课次下普通 note，或规格化的 AI备课 note 子结构；保持可编辑；
- 状态机支持当前步失败、人工重试、取消、重启恢复；不得重跑已完成讲义或已确认例题；
- 记录每步 provider/model/prompt_version、输入来源 manifest、源 content_hash、开始/完成时间和安全错误；
- 若外部调用可能已计费但响应丢失，明确提示并由老师决定是否重试；
- 退出提示可显示当前 AI 步骤，但强杀安全不依赖弹窗；
- 增加 fake provider 可控故障点和步骤级集成测试。

## 不做

token 级恢复、关闭软件后云端继续、自动改原课程文件、快速模式、通用流程编辑器。

## 验收

- 例题生成时强杀，重启后讲义仍在且只需重做例题；
- 例题失败不删除讲义，作业失败不重做前两步；覆盖原规格测试 14、26；
- 每个最终 note 可追溯到实际选中的 file_id/position/content_hash；
- 用户取消、网络断开、认证失效、模型空响应均有明确恢复路径。
