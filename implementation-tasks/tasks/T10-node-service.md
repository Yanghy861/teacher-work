# T10 · NodeService：树业务操作

**前置：** T09、T03。  
**目标：** 用事务化 Service 实现树的完整业务语义，并把它作为后续 UI/AI 的唯一入口。

## 实现范围

- 实现 create/list/rename/move/reorder/delete/restore；
- move 必须防止把节点移到自己或后代，保留整个子树，正确处理跨父节点排序；
- reorder 对并发/重复 sort_order 有确定归一化策略；
- 定义并记录安全的子树软删除/恢复语义：不得硬删，不得把早先单独删除的后代错误恢复；
- 核心写操作在单一事务内完成，失败后父子关系和排序完全回滚；
- 增加类型化 IPC，校验 UUID、标题、目标父节点和 kind 层级规则；
- 提供树路径/祖先查询，供搜索结果和面包屑复用。

## 不做

不实现课程专用表单、文件物理移动、搜索或复杂权限系统。

## 验收

- 自动测试明确覆盖原规格测试 1、2：move 不丢子节点，软删除可恢复；
- 覆盖循环移动、跨父排序、事务故障注入、删除后恢复、并列冲突；
- 重命名/移动节点不会调用任何文件系统操作；
- IPC 错误不会泄露 SQL 或 Main 堆栈。
