# T13 · 学生、简单记录与 links

**前置：** T10、T12。  
**目标：** 建立“学生文件夹 + 课程关联 + 普通记录”，不复制课程树数据。

## 实现范围

- Migration 创建 `links`：from/to/relation_type/created_at/deleted_at，并建立去重和查询索引；
- LinkService 实现关联/解除学生与班课、一对一课程/阶段，以及相关节点查询；
- 学生记录使用普通 note 子节点，支持日期、正文编辑、软删除和恢复；
- 学生页面显示姓名、当前课程、历史课程、记录；当前/历史依据明确的课程/阶段状态计算；
- 删除学生或课程时不隐式硬删另一侧数据；失效关联可恢复或被明确过滤；
- IPC 和 UI 不把 links 当作树 parent 的替代。

## 不做

本任务不做附件（T19）、逐题数据、AI 长期画像、成绩结构化分析或教务系统。

## 验收

- 同一学生可关联班课和一对一阶段，页面不复制课程内容；
- 解除/恢复关联不会删除学生、课程或记录；
- 重复 link、非法 relation_type、自关联和软删除端点均有确定处理；
- Repository、Service、IPC、页面集成测试通过。
