# T28 · DOCX Parser

**前置：** T22、T24、T04/T08 的 DOCX 决策。  
**目标：** 提取 DOCX 的标题、段落和表格文本，并保留可解释位置。

## 实现范围

- 在统一 Adapter 后实现选定 DOCX parser；
- 提取标题、普通段落、表格单元格文本；按 heading path/段落范围形成稳定 chunks；
- 保留原文用于 snippet，清理仅作用于索引副本；
- 对纯图片文档返回 `no_text`，损坏/加密/不支持结构返回 `parse_failed`；
- 解析在 worker 中执行，异常文档有超时/资源保护；
- 用 Word 与 WPS 保存的真实样本回归，记录公式、文本框、页眉页脚等已知降级。

## 不做

旧 DOC、Word 渲染、复杂版式复原、OCR、精确跳段。

## 验收

- 标题、正文、表格中的固定关键词均能搜到，并显示合理 heading/片段；
- 相同文件重复解析 chunk 顺序稳定；
- 纯图片与解析失败状态不同；
- Word/WPS 真实样本达到 Spike 约定阈值。
