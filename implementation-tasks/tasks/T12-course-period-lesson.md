# T12 · 班课、一对一阶段与课次

**前置：** T11。  
**目标：** 在极简 nodes 模型上实现班课和一对一的真实组织方式，尤其是不连续学习阶段。

## 实现范围

- 为 course 提供班课/一对一的最小创建流程；差异保存在受校验的低频元数据，不新增课程继承系统；
- 一对一课程下可创建 period，字段含可编辑标题、年级、阶段/学期、学科、开始/结束日期、active/ended；
- period 下创建 lesson；班课可按规格允许的简单层级创建 lesson；
- 提供合理默认阶段名，但老师可自由改名；
- 课程、阶段、课次页面显示面包屑和必要的创建/编辑入口；
- 层级校验防止把 period 建到非法位置，同时仍允许素材库自由 folder 树。

## 不做

不补齐中断年份，不做教务学期、课程模板、自动同步、版本继承或自动编号重排。

## 验收

- 自动场景创建“张三一对一”，再创建 `2026春·六下` 与 `2028秋·八上`，各自拥有独立课次；
- 中间年份完全不需要占位；修改阶段标题不影响课次 ID/关系；
- 班课和一对一都能通过树 UI 创建、移动和恢复；
- 覆盖原规格测试 3。
