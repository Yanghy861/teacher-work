# T42 · Windows 交付与 V1 Definition of Done 总闸门

**前置：** T01–T41 全部 DONE，所有阶段闸门已通过。  
**目标：** 产出可在真实 Windows 机器长期自用的 V1，并用证据核对完整 DoD。

## 实现范围

- 配置正式 Windows 安装包、应用版本、图标/元数据、升级路径和可理解的崩溃日志位置；
- 在干净用户环境验证安装、首次建工作区、正常退出、升级、卸载；升级/卸载不得自动删除工作区；
- 在另一空工作区验证备份恢复、重新索引、external root 重定位和重新配置 API Key；
- 逐项执行原规格第 20、22、26 节全部验收，引用自动测试、人工步骤和真实样本结果；
- 运行完整测试、typecheck、lint、production build/packaging，并记录版本、Windows/Office/WPS 环境；
- 审计包内许可证、生产依赖、秘密、调试开关和 Renderer 安全配置；
- 形成 `docs/v1-acceptance.md`，未完成项只能标 blocker 或明确 Later，不能改写为“已完成”。

## 不做

不迁移/删除用户真实资料，除非用户另行明确授权；不加首页、语义搜索、OCR、Agent、PPT 生成等非阻塞功能。

## 验收

- “管资料 / 找资料 / AI备课 / 安全”四组 DoD 全部有可复现证据；
- 安装、升级、卸载与恢复测试未损伤工作区；
- 所有 P0/P1 缺陷关闭，已知限制不造成数据风险或虚假搜索结果；
- 只有全部满足时才将 T42 与 V1 标为 DONE。
