# T26 · 全局搜索与索引进度 UI

**前置：** T25。  
**目标：** 让老师在索引未完成时也能搜索已就绪内容，并清楚知道后台发生了什么。

## 实现范围

- 顶部全局搜索框和独立结果页；支持当前节点范围与文件类型过滤；
- 结果按节点、文件、内部正文合理区分，显示文件名、树路径、原文片段、页/幻灯片/标题/sheet-cell 位置及打开按钮；
- 持续可见的索引状态：已就绪、正在准备、等待、无可搜索文本、解析失败；
- 未全部完成时立即查询 indexed 内容；界面不得用全屏阻塞等待；
- stale/missing/no_text/parse_failed 用普通老师能理解的文案，并提供查看失败详情/重试入口；
- 搜索请求支持取消或丢弃过期响应，快速输入不会显示旧结果覆盖新结果；
- 进度来自持久状态，重启后不无故显示 0。

## 不做

语义搜索、OCR、复杂查询语言、技术词 tokenizer/chunk 暴露。

## 验收

- 部分索引场景中已完成文件可搜，pending 文件不阻塞；
- 各状态、空结果、错误、missing 均有 UI 测试；
- 点击结果只通过登记 ID 打开文件，Renderer 不接收任意路径能力；
- 覆盖原规格测试 20、24 的 UI 部分。
