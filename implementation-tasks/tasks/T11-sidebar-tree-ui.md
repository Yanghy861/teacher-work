# T11 · 左侧树 UI

**前置：** T10。  
**目标：** 通过 NodeService 的类型化 IPC 完成可日常使用的受控树界面。

## 实现范围

- 实现展开/折叠、选择、新建子节点、行内重命名、软删除、拖拽移动、同级排序；
- 提供右键或 `...` 菜单，并有键盘可访问的等价操作；
- 若采用 react-arborist，先验证 Controlled Mode、稳定 key 和拖拽回滚；不合适则使用更小实现并记录理由；
- UI 以服务端返回状态为真相；乐观更新失败时必须回滚并显示可理解错误；
- 大树下避免每次交互重载整个数据库；保留选中节点与展开状态；
- 根导航至少呈现我的课程、素材库、学生、设置的入口，但不实现各页面业务。

## 不做

不做块编辑器、标签、智能筛选、复杂动画或文件拖入。

## 验收

- UI 集成测试覆盖创建、重命名、移动、排序、删除与错误回滚；
- 刷新/重启后树结构和排序与数据库一致；
- Renderer 只调用 preload 暴露的节点 API；
- 1000+ 测试节点下基本展开和移动没有明显长时间卡死。
