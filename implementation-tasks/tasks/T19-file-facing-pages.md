# T19 · 课次、素材与学生附件页面

**前置：** T13、T16、T17、T18。  
**目标：** 把 Phase 1 的树与文件服务连成老师可操作的页面，不加入搜索或 AI。

## 实现范围

- 课次页显示标题、简单备注、本节资料，并提供从素材库添加、从 external 添加、普通导入；
- 文件行提供打开、在文件夹显示、软删除/移除、来源/状态和易懂错误；
- 素材页支持自由树、文件拖入/导入、加入当前课次、从实际课保存到素材库；
- 学生页补充 managed 附件上传、列表、打开、软删除；附件不做图片理解；
- 图片提供基础缩略图/预览但不 OCR；managed Markdown 提供简单查看/编辑，写回仍走临时文件 + 原子替换，external Markdown 只读；
- external 选择器清楚提示“外部原件只读；加入本课会复制”；
- 文件页提供“刷新资料”；工作台从其启动的 Office/WPS 返回焦点或重新打开文件时自动核对该文件，元数据变化能在页面刷新；此时只要求显示“索引更新中/已更新”，不要求同步完成全文索引；
- 所有动作经类型化 IPC 与 Service 完成，Renderer 不接收任意磁盘路径能力。

## 不做

全文搜索、缩略图高级缓存、内嵌 Office 编辑、OCR、AI 分析、复杂 Markdown 块编辑器。

## 验收

- 真实操作能完成导入→打开→外部编辑→返回工作台自动核对（或手动刷新）→页面看到更新；关闭 watcher 后同一流程仍成立；
- 素材/external 加课次均产生 managed 副本；
- 学生附件与课程数据互不复制，软删除后仍可恢复；
- 空状态、missing、权限失败、复制取消都有可理解 UI。
