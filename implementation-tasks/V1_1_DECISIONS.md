# 教师工作台 V1.1 实施决策

本文件自 2026-08-22 起约束 V1.1 增量实施。V1 已在 `checkpoint-L12-pass` 完成并冻结；V1.1 只执行 `v1.1-tasks/V11-01`–`V11-05`，不得回改 L01–L12 的完成状态或重新执行已退役 T09–T42。

## 1. 产品主线

V1.1 只改善一条老师可直接感知的流程：

```text
进入课次 → 找资料并复制进本课 → 选择 Skill/填写要求 →
生成固定三类内容 → 草稿箱保存 → 原地查看/修改 → 保存到课次
```

产品规格以仓库根目录 `教师工作台_V1_1_产品与实施方案.md` 为准；参考图只提供布局和交互关系。

## 2. 已确认的简单方案

- 外部资料只支持一个根目录，按展开 lazy 浏览；不扫描、不监听、不索引、不修改原文件。
- 外部或素材加入课次时沿用 managed 原子复制，课次副本与来源完全独立。
- AI 生成以 lesson 为必需上下文，不再强制绑定 student；一对一学生信息可以自动补充，班课允许没有单个学生。
- Skill 是普通 Prompt 模板，只做名称、正文和简单 CRUD。
- 本次要求是一次请求文本，可空，不写回 Skill。
- 三个固定动作继续使用 `lecture/example/homework`，不建立 Workflow、Agent 或步骤状态机。
- 生成成功立即保存为 `draft`；“保存到当前课次”只把同一正文改为 `saved`，不复制第二份正文。
- 重新生成创建新草稿，旧草稿保留；不建立版本树。
- Preview 与 Editor 使用同一个内容区域；普通界面隐藏 token/字符等技术参数。

## 3. 不可放松的安全边界

- Renderer 只能通过类型化、运行时校验的白名单 IPC 使用外部资料能力，不能直接读取任意文件系统路径。
- 外部路径每次操作都要解析并验证仍在已登记根目录内；路径逃逸、符号链接/目录联接逃逸或未登记目标必须拒绝。
- 工作台不删除、移动、重命名或覆盖外部资料；复制失败不得留下正式 managed 半文件或数据库可用记录。
- AI 只接收老师明确选择且受预算限制的资料；Skill、要求和资料正文分区组织。
- API Key 继续使用安全存储，不进入数据库正文、日志、备份、错误信息或 Git。
- 草稿和保存成果都不得覆盖老师原资料；现有 V1 数据迁移必须无损。

## 4. 验证强度

- V11-01–V11-04：相关自动测试、`npm run typecheck`、`npm run lint`；只有改动构建配置时才额外 build。
- V11-05：完整测试、typecheck、lint、production build、portable packaging、代表性 Windows happy path 和 `git diff --check`。
- 普通 UI 不做大规模交互矩阵；安全负向测试只覆盖路径逃逸、原资料保护、Renderer/Key 边界和破坏性迁移等高风险点。
- V1.1 只有 V11-05 一个最终验收点，不建立多层企业审核流程。

## 5. Later

多 external root、外部资料全文索引、watcher/同步、Office/PDF 高保真内嵌预览、草稿历史版本树、审批/审计、流式生成、Workflow Builder、Agent、多模型步骤编排和大规模压力矩阵均不属于 V1.1。
