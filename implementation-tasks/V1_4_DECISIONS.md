# 教师工作台 V1.4「只读题库接入」冻结实施决策

**冻结日期：** 2026-08-24

**固定基线：** `checkpoint-V1.3-pass`

**产品主规格：** `教师工作台_V1_4_只读题库接入_产品与实施方案.md`

## D01 · 旧题库永远只读

- 不修改、迁移、重命名或同步 `E:\Wss_Tiku` 中任何文件。
- 导出器用 readonly + query-only 打开旧数据库，并拒绝把输出写入旧题库根目录内部。
- 只导出 `ready + reviewed` 题目及其直接依赖，不导出账号、认证、Key、日志、原始上传、pending 或 archived 内容。

## D02 · 更新方式是完整快照替换

- `.tqbank` 是带格式版本和统计信息的自包含 SQLite 单文件。
- 导入先 staging、校验、原子替换；失败保留当前有效快照。
- V1.4 不合并多个包，不监听旧库，不做增量同步。

## D03 · 题库是工作台原生页面

- 保留现有 `App`、导航和所有 V1.3 页面；只新增一个 `question-bank` 页面状态。
- 默认只显示搜索 / 筛选 / 结果列表，不永久显示题目详情。
- 宽窗口详情从右侧展开；窄窗口使用下方详情；关闭后恢复完整结果区。

## D04 · 复用搜索接口

- Main 提供独立的 package info、filters、search、detail、import 和 copy 能力。
- Renderer 只能使用类型化白名单接口；搜索和筛选全部经过运行时校验和参数化 SQL。
- 未来其他入口可复用 search，不把 UI 状态写入服务。

## D05 · 单题复制是独立副本

- 素材库复制复用 `ManagedFileService`；课程复制必须指定有效 lesson。
- 复制后不依赖当前快照，更换快照不会破坏已有副本。
- 不提供多题批量复制、试题篮或组卷。

## D06 · 不扩大产品范围

- 不做错题本、推荐、成绩、知识图谱、学生侧题库、AI 自动处理或新备课工作流。
- 不改变 V1.1 备课、V1.2 课程 / 学生 / 进度和 V1.3 快速建课模型。
- V1.4 不运行 portable / installer packaging。
