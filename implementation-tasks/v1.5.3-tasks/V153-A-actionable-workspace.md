# V153-A · 课件动作化与 AI 修改工作台

**前置：** `checkpoint-V1.5.2-pass`。设计基准：`tmp/v1.5.3-mockup.png`（已获产品负责人确认）。

## 范围

- 教学内容改为两个分区：**课件 / 修改记录**；移除独立"AI 备课"tab；
- 课件分区工具条：无课件 → 「AI 新建备课」；有课件 → 「✦ AI 修改」（主按钮）；沉浸阅读/系统打开/定位保留；
- 工作台模式（点击 AI 入口进入，两栏）：
  - 顶栏 "AI 修改 · 课次标题" + 「退出修改，回到课件」；
  - 左栏：参考资料勾选 + 本课修改记录（修改中/已确认时间线）；
  - 右栏：**修改要求提示词框常驻** + Skill + 「生成修改方案」；方案审阅（确认并生成 / 重新出方案 / 放弃）；生成后 ✦AI 修改说明摘要卡 + 视图切换（并排对照 | 修订标注 | 仅看新版）+ 保存为新版本 / 重新生成 / 放弃修改；
- 课件列表**只显示一个当前版**（"标题 · 第 N 版 · 当前"）；历史收进「🕘 历史版本（N）▾」折叠入口，可查看/恢复；原件等非版本文件照常列出；
- 正文默认打开当前版；发布成功后回课件区并提示"正文正在展示最新版"；
- 新建模式（无课件）：工作台同布局，按钮为「生成讲义/例题/作业」，走既有生成；
- AI 生成/方案/发布逻辑与既有 IPC 全部平移复用；不新增 schema/migration/Service/IPC。

## 不做

- 修订标注的红绿自动 diff 算法（首版可退化为"仅看新版+说明卡"，若逐字 diff 复杂则写 Later）；历史版本删除/清理策略（V1.5.4 候选）。

## 验证

- 契约测试更新（两分区、AI 入口、提示词常驻、单当前版+历史折叠、三视图切换）；
- 相关测试 + typecheck + lint + build + `git diff --check`；
- 隔离 Electron UI smoke（中继式 AI 走通 看课件→AI 修改→方案→确认→对比→发布→回课件）。
