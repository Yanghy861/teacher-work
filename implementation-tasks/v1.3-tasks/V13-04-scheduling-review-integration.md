# V13-04 · 排课、确认页与课程页完整接入

**前置：** V13-03 `DONE`。

**结果：** 四步快速建课成为课程页主入口，可用规律、自由日期或暂不排课一次创建课程，并返回新课程详情；现有维护入口仍可用。

## 最小范围

- 第三步三段式模式：按规律排课 / 自由选择日期 / 暂不排课；无“不重复”。
- 规律排课表单、显式日期预览、例外排除、逐节改时和清空。
- 自由日期月历弹层、多月切换、多选 / 取消、`添加 N 节课` 与数量不一致确认。
- 课程时长在三种模式中均可设置，并按课次进入最终请求。
- 第四步展示课程、学生、阶段、课次和全部 / 部分 / 未排摘要；各块可返回对应步骤修改。
- 点击创建调用唯一 `createCourseSetup()`；提交中防重复，失败保留输入并定位步骤。
- 课程页主入口改为“快速建课”；“仅创建课程”保留在相邻次级入口。
- 成功后关闭向导、选中新课程、刷新 overview，显示可关闭成功提示，并提供进入第 1 课备课的主动作。
- 现有新建学生、阶段、课次、学生关系、设置时间、点名和 Current Lesson 流程不得退化；现有设置时间交互可读取 / 维护 duration。
