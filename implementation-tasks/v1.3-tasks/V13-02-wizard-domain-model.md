# V13-02 · 向导领域模型、名单与排课预览

**前置：** V13-01 `DONE`。

**结果：** Renderer 侧纯函数 / view model 能稳定生成最终请求所需的学生、课次、日期和确认摘要；本任务不接入课程页入口。

## 最小范围

- 四步向导状态模型与逐步校验。
- 名单逐行 trim、空行忽略、本次同名去重、活动学生精确匹配和重名待确认状态。
- 阶段软推荐：1 月上一年秋季，2–7 月当年春季，8–12 月当年秋季。
- 空课次和教学计划解析；统一 1–100 上限与固定错误提示。
- 规律排课：本地日历每周 / 每两周、排除、顺延、改单节和清空单节。
- 自由日期：月历多选、排序、空课次数量同步确认、教学计划不足日期时保留未排课。
- 本地日期时间到严格 UTC ISO 的转换；不持久化 recurrence。
- 全部 / 部分 / 完全未排三种确认摘要。
- 将最终状态转换为明确的 `CreateCourseSetupRequest`。

## 必证边界

- 未解决重名使第一步不可继续；软删除学生不进入自动匹配。
- 一对一名单最多一位；班课允许空名单。
- 1/100/101 个课次与教学计划有效行；空主题行为明确。
- 每周 / 每两周、跨月 / 跨年、本地跨日、日期排除顺延。
- 日期数少于教学主题时不删除主题；全部 / 部分 / 未排摘要准确。
- 时长在未排课模式中仍进入每节 lesson 的最终请求。
