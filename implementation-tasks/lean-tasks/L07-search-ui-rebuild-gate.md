# L07 · 搜索 UI、刷新重建与阶段闸门

**前置：** L05–L06。
**结果：** 老师能搜索真实资料、看到来源位置，并在文件变化或索引删除后恢复搜索；完成后等待 Sol 审核。

## 最小范围与验收

- 提供全局搜索框/结果页，显示文件/节点、路径、片段、位置和打开按钮。
- 索引状态只需“准备中/可用/无文本/失败”；允许已完成内容先搜，不要求精确持久百分比。
- 提供“重建搜索索引”；删除 `search.db` 或应用重启后按当前文件 Hash 重新排队。
- 修改 PPTX 后返回工作台或手动刷新，最终新词出现、旧词消失；当前处理中断可整文件重做。
- 用真实样本子集完成中文/数学/多格式 smoke；不要求大量文件强杀矩阵、事件循环精确指标或旧 11 类查询全部重演。
- 运行完整测试、typecheck、lint、production build，形成简短 `docs/phase2-acceptance.md`。
