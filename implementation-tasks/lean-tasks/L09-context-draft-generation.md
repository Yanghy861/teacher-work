# L09 · 选择资料并生成可编辑草稿

**前置：** L08、L07。
**结果：** 老师可以选择本地资料，分别生成讲义、例题和作业，并立即保存为可编辑 note。

## 最小范围

- 从当前课、素材和搜索结果勾选文件/片段；只发送老师明确选择的内容，并设置简单字符/token 上限。
- 记录所选 file ID、位置、provider/model 和 prompt version；不要求逐片段 content_hash manifest 或构建时竞争重校验。
- “生成讲义”“生成例题”“生成作业”是三个独立操作；每次收到完整结果立即保存为普通可编辑 note。
- 失败或应用退出时，本次未完成请求由老师重新点击；已保存 note 不丢失。
- 不建立 `prepareLesson()` Workflow、步骤级状态机、强杀精确续步或通用 Agent。

## 验证

- 未选择内容不会发送；超预算截断；生成结果能编辑和保存。
- fake provider 网络失败/空响应后可手动重试，已有 note 不受影响。
- 运行相关测试、typecheck、lint。
