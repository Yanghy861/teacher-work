# L02 · managed 文件、素材副本与安全打开

**前置：** L01。
**结果：** 老师可以导入资料、放入课次/学生/素材库、复制独立副本并用系统应用打开。

## 最小范围

- 建立 `files` 最小字段和 `files/objects/<uuid>/` 受控对象布局；树标题变化不移动物理文件。
- 文件选择器导入到 managed；实现打开、在文件夹显示、软删除/恢复。
- 素材加入不同课次时创建真实独立副本并保留可选 `origin_file_id`。
- 复制先写同目录临时文件，完成基本大小/可读性校验后重命名，再写数据库。
- Main 只接受登记 file ID，不接受 Renderer 传入任意绝对路径。
- 不实现 external roots、后台目录扫描、文件去重、断点续传、精细复制进度或取消。

## 验证

- 导入→打开；素材复制到 A/B 两课次后修改 A 不影响素材与 B。
- 路径穿越/未登记文件打开被拒绝；模拟复制失败不产生 available 半文件。
- 运行相关测试、typecheck、lint。
