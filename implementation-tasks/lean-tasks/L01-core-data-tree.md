# L01 · 核心数据、课程学生与基础树 UI

**前置：** T08 Sol `PASS`。
**结果：** 老师可以建立课程、阶段、课次和学生，写普通记录，并用基础树/列表完成日常管理。

## 最小范围

- 用现有 SQLite Migration 建立 `nodes` 与最小课程—学生关联；ID 使用 `crypto.randomUUID()` 即可。
- NodeService 支持创建、读取、重命名、移动、排序、软删除和恢复；节点内容写入使用事务。
- 支持班课、一对一、不连续阶段和课次；学生可关联课程并拥有普通 note 记录。
- Renderer 只通过类型化 IPC；实现按钮/菜单驱动的树或列表。拖拽、完整键盘等价和大树专项优化不是必需。
- links 可使用简单关系表；解除关系可以硬删除后重建，不要求关系本身进入回收站。

## 验证

- 自动测试覆盖嵌套移动不丢子节点、循环移动拒绝、节点软删除恢复、不连续阶段和学生关联。
- 完成一条 UI smoke：创建课程 → 阶段 → 课次 → 学生 → 记录。
- 运行相关测试、typecheck、lint；不因 1000+ 节点或拖拽未实现而阻塞。
