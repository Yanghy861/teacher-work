# L03 · 资料页面与刷新核对

**前置：** L02。
**结果：** 课次、素材和学生页面可以查看与操作资料，外部编辑后能刷新到最新版本。

## 最小范围

- 文件列表提供导入、打开、显示位置、移除/恢复、来源和简单错误提示。
- 素材页可导入并加入当前课次；学生页可添加 managed 附件。
- 工作区启动、从本应用启动的外部编辑器返回焦点、重新打开文件或点击“刷新资料”时比较 size/mtime，必要时在后台计算 Hash。
- Hash 变化更新文件元数据并发出简单 contentChanged 信号；Hash 未变不重复工作。
- watcher 完全可不实现；图片缩略图、Markdown 编辑器和复杂空状态可按实现成本降级。

## 验证

- 用临时 DOCX/PPTX/XLSX 或普通 fixture 修改文件，零 watcher 事件时手动刷新/重新打开仍能发现变化。
- 基础 UI happy path 可操作；运行相关测试、typecheck、lint。
