# L11 · 空闲状态备份与新工作区恢复

**前置：** L10 Sol `PASS`。
**结果：** 老师可以在暂停后台任务后备份工作区，并恢复到新的空目录。

## 最小范围

- 开始备份前暂停应用写入/索引并提示关闭外部编辑；不支持无停顿并发备份。
- 使用 SQLite backup API 创建 workspace.db 快照，复制 managed 文件并生成含版本/时间/数量的 manifest。
- 排除 `search.db`、cache、日志、API Key/密文和 external 原件。
- 输出先写 staging，完成后发布；恢复只允许新的空目录，做基本相对路径校验、文件数量/总大小上限和数据库可打开检查。
- 恢复后重新配置 Key、重新建立搜索索引。
- 不实现增量/云/加密备份、并发变化重试、完整孤儿系统或恶意压缩包攻防矩阵。

## 验证

- 一次备份→新目录恢复往返，核心课程/学生/资料/note 一致；原工作区失败时不变。
- 备份中不存在 Key、search.db 和 cache；路径穿越条目被拒绝。
- 运行相关测试、typecheck、lint；涉及打包格式时运行 build。
