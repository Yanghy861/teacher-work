# V152-C · 已有课件改进流程

**前置：** V152-B `DONE`。

## 范围

- 已有正式课件时可发起"改进"：选择参考范围（正式课件/课次资料）、填写修改要求；
- AI 先输出可审阅的**修改方案**：老师可确认、拒绝、修改要求后重出方案；
- 确认方案后才生成新工作副本；提供新旧内容对比、重新生成、放弃本次修改；
- 方案与要求纳入 ai_metadata 追溯字段（复用 notes，不新增 schema）；prompt 走既有 Gateway 固定版本化模板；
- **中继式 AI 验收（见 D15）**：本地 OpenAI-compatible 服务挂起请求并暴露完整 prompt，由实施代理按真实语义现写方案与内容回填，检验 prompt 组装与两步确认流；固定 fake provider 自动测试继续保留。

## 不做

- 版本发布与时间线（V152-D）；多轮自由对话、流式输出、Workflow 状态机。

## 验证

- fake provider 覆盖方案确认/拒绝/重新生成/放弃路径与原资料保护；
- 中继式验收至少一轮真实语义内容（方案 + 生成）；
- 相关测试、typecheck、lint、production build、`git diff --check`。
