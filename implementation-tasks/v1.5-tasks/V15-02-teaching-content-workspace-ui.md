# V15-02 · 教学内容工作台与宽正文

**前置：** V15-01 `DONE`。

## 范围

- 建立共享 course / period / lesson 的“课件 / 备课 / 草稿箱”三分区；
- 顶部显示上下文，并提供临时“切换课程 / 课次”抽屉、上一课、下一课和来源返回；
- 课程 / 课次目录默认不常驻，选择完成后收回；
- “课件”只常驻 220–260px 本课目录与正文，复用 LessonFilesSection / LessonMaterialReader；
- 加入沉浸阅读，收起 / 恢复本课目录，不丢失文件和阅读位置；
- “备课”复用资料选择、Skill、本次要求、生成、预览、编辑和保存；保存后可原地回到课件；
- “草稿箱”展示全局待处理草稿和所属上下文；打开后切到对应 lesson 的备课；
- 空 lesson、已结束课程、学生历史课程和窄窗口使用明确可读状态；
- 不加入文件拖拽、课程级共享文件或新 AI / 草稿数据能力。

## 验证

- 三分区上下文保持、抽屉选择、上一课 / 下一课和 Current Lesson 不变测试；
- 课件文件切换、刷新、系统打开、空状态、沉浸阅读和阅读位置恢复测试；
- 草稿 → 对应课次备课 → 保存 → 课件的 Renderer 流程；
- 约 1200px 窗口正文宽度证据：无常驻课程目录，本课目录为 220–260px，正文占其余宽度且不小于既有阅读页；
- 窄窗口无页面级横向溢出；
- typecheck、lint、build、`git diff --check` 和隔离 Electron UI smoke；
- 不运行 portable / installer。
