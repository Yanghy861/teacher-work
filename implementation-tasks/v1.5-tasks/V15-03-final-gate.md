## 代表性本地 Windows 流程

```text
左侧课程 → 选择活动课程 → 单击任意课次
→ 验证只改变 Viewed、不改变 Current、未进入备课
→ 双击同一课次 → 打开课件
→ 返回课次目录 → 点击“查看课件” → 打开同一课件
→ 在课件区上一课 / 下一课 / 指定课次切换并阅读 Markdown、图片和普通文件
→ 点击“开始/继续备课” → 进入备课 → 返回课程
→ 恢复原课程、原课次和课件区
→ 学生 → 在读课程 → 课程 → 课次 → 课件 → 返回原学生
→ 学生 → 历史课程 → 只读浏览已有课件
→ 快速建课、设置时间、点名、确认已上、调整 Current、题库加入课次仍可用
```
