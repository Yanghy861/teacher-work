## 代表性本地 Windows 流程

```text
左侧课程 → 选择活动课程 → 单击任意课次
→ 验证只改变 Viewed、不改变 Current、未进入备课
→ 双击课次 / 查看教学内容 → 教学内容的课件分区
→ 约 1200px 下只显示主导航、本课 220–260px 目录和宽正文
→ 沉浸阅读收起目录 → 恢复目录与原文件 / 阅读位置
→ 切换课程 / 课次抽屉 → 选择后自动收回
→ 上一课 / 下一课连续浏览且 Current 不变
→ 同一课次切到备课 → 选择资料 / 填要求 / 打开或生成现有草稿
→ 保存后切回课件查看成果
→ 现有草稿兼容入口 → 自动建立对应上下文并进入备课
→ 学生 → 在读课程 → 课次 → 教学内容 → 返回原学生
→ 学生 → 历史课程 → 只读浏览已有课件
→ 直接打开教学内容分别验证最近位置恢复和无位置选择空状态
→ 快速建课、设置时间、点名、确认已上、调整 Current、题库加入课次仍可用
```
