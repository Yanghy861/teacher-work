## 7. V1.5.3.1 · AI 修改范围分流增补验收

### 7.1 产品行为

- **修改这份：** 锁定一份可读文件作为唯一修改对象；补充参考为可选复选项，不会改变修改对象；方案确认后输出该文件的完整修订 Markdown；
- **整课重做：** 自动使用当前正式版本作为整课基线，没有正式版本时使用进入工作台时已有的可读材料；确认后统一生成一份包含讲义、典型例题、课堂练习和课后作业的完整课件 Markdown；
- 无课件时继续使用 AI 新建备课，只有新建模式保留讲义 / 例题 / 作业快速生成；
- 历史版本不进入新修改范围；修改要求与 Skill 在模式切换时保留，未确认方案与对比状态清除。

### 7.2 生成、恢复与发布

- 方案读取按 `DRAFT_DEFAULT_MAX_CHARS` 统一预算，先读取修改对象或整课基线，剩余预算才读取补充参考；发生截断时页面明确提示；
- 单文件写入 `【AI修改方式：单文件】` 与 `【修改对象：文件名】`；整课写入 `【AI修改方式：整课重做】` 与 `【自动基线数量：N】`；
- 恢复时按 metadata sources 的首次出现顺序区分基线和补充参考，并恢复模式、要求、Skill、目标、参考与对比基线；旧无标记草稿继续按既有逻辑打开；
- 节点名称与发布确认分别显示“单文件修订 / 整课重做”；发布仍复用既有 managed 原子新版本通道，旧版本保留。

### 7.3 隔离 Windows 中继流程

- 新建隔离课程，初始正式课件为“第 1 讲 实数综合 · 第 1 版.md”，另有“教学补充参考.md”；
