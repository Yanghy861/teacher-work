## 安全边界复核（V1.6 重点）

- **MinerU token 与 AI Key 同规范**：safeStorage 多槽加密（`teacher-workbench-mineru-key.bin`），不回显、不落 DB、不进日志与备份，仅注入请求 Authorization 头；判活请求 GET batch/<探测 ID>。
- **上传对象仅限 managed 副本**：外部根目录只读资料无任何上传入口；`enhanceFile` 仅接受 active、≤200MB、office/pdf/图片 的 managed 文件。
- **结果下载白名单 + zip 防穿越**：仅 mineru.net 及子域、`*.aliyuncs.com`；fflate 内存解压，条目路径 resolve 后必须锚定在临时目录内，解压后临时目录即删。
- **流式通道**：`ai:stream-event` 为白名单推送通道（不在 invoke 白名单），载荷经 `isAiStreamEvent` 校验；reasoning 原文只留在 Main、仅推累计字数。
- **Local-first 与渲染隔离不变**：Renderer 不直接访问 SQLite/Node/文件系统/秘密；AI 产物绝不覆盖老师原资料。
