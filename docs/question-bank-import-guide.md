# V1.4 题库导入与更新说明

## 第一次导入

1. 打开教师工作台，进入左侧“题库”；
2. 点击“导入题库快照”；
3. 选择扩展名为 `.tqbank` 的完整快照；
4. 校验和导入完成后即可搜索和筛选。

当前本地已经生成的题库快照位于：

```text
D:\teacher_work\tmp\Wss题库_2026-08-24.tqbank
```

真实快照只保存在本机，不进入 Git。

## 未来题库增加后的更新

从旧题库根目录重新导出一个完整快照：

```powershell
npm run question-bank:export -- `
  --source-root "<旧题库根目录>" `
  --output "D:\teacher_work\tmp\Wss题库_新的日期.tqbank" `
  --source-name "Wss_Tiku 题库"
```

然后在题库页点击“更换题库”并选择新文件。V1.4 每次替换一个完整快照，不合并多个增量包。

## 必须保持的边界

- 输出文件必须放在旧题库目录之外，导出器会拒绝写入旧根目录内部；
- 导出器以 readonly + query-only 方式打开旧数据库；
- 已存在的输出文件不会被覆盖，必须使用新文件名；
- 只导出 `ready + reviewed` 的可用题目及其直接关联图片；
- 不导出账号、认证、Key、日志、原始上传、pending 或 archived 题目；
- 导入素材库或课次后得到独立副本，更换题库不会使副本失效。
