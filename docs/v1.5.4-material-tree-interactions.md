# V1.5.4 · 素材库树交互修正

**日期：** 2026-08-31  
**基线：** `checkpoint-V1.5.3-pass`  
**决策：** D18

## 1. 问题

V1.5.3.2 已建立素材库逻辑目录，但 Renderer 仍把目录树当作静态列表：子目录始终递归显示，箭头不能控制展开；新目录主要依赖页面右上角；文件和文件夹没有拖拽；右键没有成为主要的就地操作入口。这让“逻辑目录”在使用上更像筛选列表，而不像桌面资料树。

## 2. 目标交互

- 文件夹名称负责选择目录，独立箭头负责展开/收起；有子目录时显示真实状态，没有子目录时保留稳定占位。
- “我的文件夹”标题提供顶层新建按钮；右键“我的文件夹”也可新建顶层目录；右键任意文件夹可新建子文件夹、重命名、删除。
- 素材行可拖入任意文件夹；拖到“待整理”时清除目录归属。
- 文件夹拖到另一文件夹中心时成为其末尾子目录；拖到目标行上/下边缘时插入目标同级前/后；拖到“我的文件夹”时成为末尾顶层目录。
- 文件右键菜单提供打开、在资源管理器中显示、复制到当前课次、移动到任意目录/待整理和移除。
- 拖拽进行中提供明确目标高亮；完成或失败后刷新 overview 并显示应用内状态消息。

## 3. 安全与数据语义

- 文件拖拽复用 `moveFile(fileId, folderId)`，只更新 `material_folder_items`。
- 文件夹拖拽复用 `reorderFolder` IPC 通道，请求扩展为 `{ folderId, parentId, sortOrder }`。
- Main 在事务中校验目标目录存在、目标不是自身或后代；跨父级时同时规范旧父级与新父级的 `sort_order`。
- 底层 managed 文件对象路径、文件名、内容和课程/学生副本关系均不改变。

## 4. 非目标

- 外部资料树与素材库跨页面拖拽；
- 从 Windows 资源管理器直接拖入或把 managed 文件拖出应用；
- 多选、批量移动、快捷键剪切粘贴；
- 物理目录同步、云同步或文件系统重命名。

## 5. 验收

1. 根目录和嵌套目录可反复展开/收起，选择目录不强制改变其他分支状态。
2. 可在“我的文件夹”就地新建顶层目录，也可在文件夹右键菜单新建子目录。
3. 文件可拖入目录并拖回“待整理”，重启后归属保持。
4. 文件夹可同级排序、跨级移动和移回顶层；拖入自身/后代被 Main 拒绝且树不损坏。
5. 文件与文件夹右键菜单可用，点击空白处或 Escape 关闭。
6. 全量测试、typecheck、lint、production build 与 `git diff --check` 通过；不运行 portable/installer。
