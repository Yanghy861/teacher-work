# V1.5.6 · 可维护性技术债清理

**日期：** 2026-08-31  
**基线：** `checkpoint-V1.5.5-pass`（V155-E 验收后创建；创建前本链任何任务不得置为 `IN_PROGRESS`）  
**决策：** D20（`implementation-tasks/V1_5_DECISIONS.md`）  
**任务链：** `implementation-tasks/v1.5.6-tasks/` V156-A–V156-E

## 1. 问题

2026-08-31 全面分析同时确认了四类不改用户可见行为、但随规模增长持续放大的可维护性债务：

1. **工具函数重复**：`toErrorMessage` 在 16 个 Renderer 文件各定义一遍（仅回退文案不同），`formatBytes` 重复 4 处。
2. **快速建课向导双实现**：`quick-course-wizard.tsx` 与 `quick-course-wizard-full.tsx` 各自重实现 `wizardSteps`、`requestClose`、`updateRoster`、`resolveDuplicate`、`goToLessons`、`selectLessonMode`、`updateEmptyLessons`、`updateTeachingPlan` 等全套编排，存在分叉风险。
3. **整域 overview 重拉**：每页独立 `core.getOverview()` 拉全量、每次变更后整域重拉（素材库一次动作拉素材 + core 两份），页面间快照可能漂移；`buildCourseSummaries` 为 O(课程×节点)。
4. **样式与测试基建缺口**：`styles.css` 3,179 行零设计令牌，全部硬编码 hex；vitest 无覆盖率 provider，覆盖声明全部是定性的；draft-panel、teaching-content-page、course-detail 等大型组件仅靠字符串断言（`toContain`）钉住，对运行时结构无所证明。

## 2. 方案

### 2.1 共享工具收敛与覆盖率基线（V156-A）

- 新建 `src/renderer/ui-utils.ts`：`toErrorMessage(error: unknown, fallback: string)` 与 `formatBytes`，逐文件替换 16 + 4 处本地定义；受影响的字符串合同测试同步核对断言。
- devDependency 增加 `@vitest/coverage-v8`（与 vitest 4 同主版本），script 增加 `"test:coverage": "vitest run --coverage"`；**只出报告、不设阈值**，把基线数字记入验收文档，作为后续增量设阈值的依据。

### 2.2 CSS 设计令牌（V156-B）

- `styles.css` 头部增加 `:root` 调色板令牌（indigo 主色系 `#4338ca/#6366f1/#3730a3/#eef2ff`、slate 文本四级 `#1f2937/#334155/#64748b/#94a3b8`、边线 `#e2e8f0`、底色 `#f5f7fb`、danger `#b91c1c/#fff7f7`）与圆角/间距令牌；对现有硬编码 hex 做**机械等值替换**，视觉零变化；`question-bank.css` 同步；此后新页面一律引用令牌。

### 2.3 overview 共享缓存（V156-C）

- App 层新增 `CoreOverviewProvider`（与 `AppDialogProvider` 同级）：持有快照 + `reload()` + `invalidate()`；页面经 `useCoreOverview()` 消费；变更动作完成后 `invalidate()` 触发单次共享重拉；`files.onContentChanged` 接同一失效口。**纯 Renderer 改动**，零 IPC/schema 变化，符合 V1.5 系"只改 Renderer"约束。
- 分页迁移，一次一页、每页跑该页既有 UI 合同测试：course-dashboard → students-page → course-detail → draft-panel；字符串测试钉住 reload 形态处同步更新断言（断言意图不变）。

### 2.4 向导去重与静态渲染测试（V156-D）

- 抽共享编排 hook `useQuickCourseWizardOrchestration`（或并入 `quick-course-wizard-model.ts`），两个向导组件只保留各自的步骤渲染层，入口行为不变；以 `v1.3-*` 静态渲染测试为回归网。
- 静态渲染测试升级（**加法而非替换**，字符串合同测试继续钉文案）：按优先级补 `renderToStaticMarkup` 测试——`managed-files-panel` + `material-tree`（树结构、拖拽 affordance 类、aria 属性、右键菜单 DOM 骨架）→ `course-detail` LessonsSection 初始渲染（阶段默认收起、徽章）→ `draft-panel` 初始态（收件箱/备课两模式）→ App 外壳（8 项导航）。拖拽的运行时验证仍按 V1.5.4 先例归产品负责人手工确认单。

## 3. 安全与数据语义

- 全部为 Renderer 层与测试基建改动，不触碰 Main/Preload/IPC/schema；
- 不改变任何页面行为、文案与数据流语义；overview 缓存对页面暴露相同的数据快照，仅消除重复拉取。

## 4. 非目标

- 不引入路由库、全局 store、CSS 框架或设计系统依赖；
- 不设覆盖率硬阈值（本版只记录基线）；
- 不删除或降级现有字符串合同测试；
- 不运行 portable/installer 打包，不自动 push。

## 5. 验收

1. 工具收敛后全量测试、typecheck、lint 通过；`test:coverage` 可运行并产出基线数字。
2. 令牌替换后 production build、响应式合同测试与手工冒烟通过，视觉零变化。
3. overview 缓存迁移后每页行为不变，单次变更仅触发单次共享重拉（日志可证）。
4. 向导去重后 `v1.3-*` 全组测试通过；新增静态渲染测试进入套件。
5. 全量测试、typecheck、lint、production build、`git diff --check` 与代表性 Windows 冒烟（快速建课、课程页、教学内容、素材库）通过。
