### 宽度与溢出证据（DOM 实测）

- 1200×800 窗口（视口 1184px）：主导航 104px + 本课课件目录 250px + 正文约 1026px；`scrollWidth ≤ clientWidth`，无页面级横向溢出。
- 沉浸阅读：目录收起后正文 1041px；恢复后目录 250px。
- 窄窗口 960×700（视口 944px，应用允许的最小宽度）：目录 250px、正文 767px，无页面级横向溢出。`@media (max-width: 760px)` 防御性规则因最小窗口宽度 960px 在常规缩放下不可达，属额外保险；契约测试保证其存在。
- 正文阅读面积（约 1026px）大于旧课程详情四列布局下的正文区域，满足“不得小于现有课次资料阅读页”。

## 4. 过程中发现并修复的缺陷

**缺陷：** 从学生页“进入课程”（尤其是历史课程或第二门在读课程）后，课程页显示的是列表第一门可见课程，而非目标课程；“返回学生”后学生详情同理回退到第一位学生。

**根因：** `CourseDashboard` 与 `StudentsPage` 挂载时概览数据为空，兜底 effect 立即用空列表把外部传入的选择清空，加载完成后又选中第一项。该逻辑为 V1.2 时期遗留；V1.2 冒烟使用的目标课程恰好是列表第一门活动课程，因此未暴露。非 V1.5 引入，但影响验收条目“从课程和学生进入、返回……恢复合理上下文”。

**修复：** 两个页面的兜底选择 effect 增加 `if (loading) return` 守卫（数据加载完成前不做兜底），并把 `loading` 加入依赖。无 schema、Service、IPC 变化。

**回归测试：** `tests/v1.2-course-ui.test.ts`、`tests/v1.2-students-ui.test.ts` 各新增 1 项契约测试；修复后在隔离 production 应用中实测：王小刚 → 进入历史课程 → 自动切到“已结束”筛选并选中寒假班（“重新开启”可见、确认已上禁用）→ 教学内容 → 返回学生精确回到王小刚详情。
