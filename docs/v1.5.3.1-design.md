# V1.5.3.1 · AI 修改范围分流设计

**状态：** 已冻结，待实施  
**日期：** 2026-08-30  
**归属：** V1.5.3 最终验收前的小版本修正

## 1. 目标

AI 修改先明确“改什么”，再选择“额外参考什么”。已有课件支持两种典型需求：

1. **修改当前文件：** 锁定一份可读文档，其他文件保持不变；
2. **整课重做：** 自动读取当前正式课件，没有正式版本时读取本课现有可读内容，生成一份完整课件新版本。

无课件时保持既有 AI 新建备课，继续允许分别生成讲义、例题和作业。

## 2. 界面规则

- 课件区有课件时显示“✦ 修改这份”和“整课重做”；当前选中图片或不可读附件时禁用“修改这份”；
- 工作台顶部使用“修改当前文件 / 整课重做”分段控件；切换模式保留老师要求和 Skill，清除未确认方案；
- 左栏顺序为“修改对象 → 补充参考（可选）→ 本课修改节点”；复选框只用于补充参考；
- 单文件模式默认目标来自课件阅读器，也允许在非历史可读文件之间单选切换；
- 整课模式只读展示自动基线；最高版本为当前正式版，旧版本永不进入目标和参考候选；
- 已有课件的两种模式都先生成方案再生成工作副本；快速生成讲义/例题/作业只属于新建备课。

## 3. 生成与发布

- 单文件方案明确区分“修改对象正文”和“补充参考”，确认后输出目标文件的完整新版 Markdown；
- 整课方案覆盖结构、难度、例题、课堂互动和作业衔接，确认后统一以 `lecture` 类型生成完整课件 Markdown；
- 整课结果内部可含讲义、典型例题、课堂练习和课后作业板块，但正式发布仍是一份 `课次标题 · 第 N 版.md`；
- 单文件目标始终位于生成 sources 的第一项；模式写入既有 `aiMetadata.requirement` 可读标记，恢复时结合 sources 识别；
- 继续复用现有原子发布通道，不覆盖老师原资料。

## 4. 文件范围

- 最高 `第 N 版` 文件为当前正式版本，其余版本进入历史；
- 非版本文件是本课当前材料，可作为单文件目标或补充参考；
- 整课已有正式版本时以正式版本为基线，其他当前材料为可选参考；
- 整课没有正式版本时以进入工作台时已有的全部可读材料为基线，之后新增文件自动成为补充参考；
- 不依赖 `originFileId` 推断用途，不新增文件角色字段。

## 5. 技术边界

- 新增 Renderer-only `PrepLaunchIntent`，通过 `TeachingContentTarget` 把 mode / targetFileId 传入 DraftPanel；
- 抽取当前版、历史版和当前材料分类纯函数，课件区与工作台共享；
- 方案拼接按 `DRAFT_DEFAULT_MAX_CHARS` 控制正文预算，基线优先、参考使用余量，发生截断时明确提示；
- 不新增 schema、migration、Service、IPC、多文件版本组或批量原子发布。

## 6. 验收
