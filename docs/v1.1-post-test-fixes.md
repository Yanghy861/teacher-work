# V1.1 测试后小修复记录

**日期：** 2026-08-23

**范围：** V11-05 完成后的个人开发版体验修复

**交付方式：** 开发模式验证；本轮不重新打包 portable

## 已修复问题

1. **隐藏 Electron 默认菜单**：移除 Windows 窗口顶部的 `File / Edit / View / Window` 默认菜单。
2. **工作区自适应撑满**：移除主要页面的固定最大宽度，内容使用全局导航右侧的剩余窗口空间；最左导航保持固定，长内容在右侧独立滚动。
3. **整体布局紧凑化**：缩小页面边距、卡片间距、圆角和阴影，不在普通界面展示版本号、Electron 版本或 schema 等技术信息。
4. **图标式全局导航**：删除与左侧导航重复的页面大标题；全局导航改为 104px 白色窄栏，使用图标加文字并突出当前栏目。
5. **已移除资料可彻底删除**：原“移除”继续作为可恢复的软删除；“已移除资料”新增“彻底删除”，二次确认后删除工作台 managed 副本、数据库记录、课次/学生关联和派生搜索索引。外部原文件不受影响。

## 彻底删除边界

- 活跃资料不能直接彻底删除，必须先执行“移除”。
- 删除前明确提示不可恢复。
- 如果 managed 文件正被其他程序占用，删除失败时保留工作台记录，老师可以关闭占用程序后重试。
- 彻底删除只操作工作台受控对象目录，不接受 Renderer 提供的任意文件路径。
- 已有 AI 草稿正文继续保留，但无法再从已彻底删除的来源重新生成。

## 开发版重启说明

Renderer 页面可以热更新，但 Electron Main 和 Preload 不会随页面热更新自动替换。凡是本轮新增 IPC 或修改 Preload 后，必须：

1. 关闭教师工作台窗口；
2. 关闭原开发终端，确认旧开发进程已经结束；
3. 重新运行仓库根目录的 `start-dev.bat`。

若只刷新页面，可能看到 `window.teacherWorkbench.files.permanentlyDeleteFile is not a function`。该错误发生在 Renderer 调用旧 Preload 时，IPC 尚未发出，因此不会删除资料。
