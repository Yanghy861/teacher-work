## 2. 功能证据

- `.tqbank` 使用自包含 SQLite 完整快照；导入经过 staging、结构与元数据校验后原子替换，失败继续使用上一个有效快照。
- 工作台以 SQLite readonly + query-only 模式访问当前快照；Renderer 只能通过类型化白名单 IPC 查询，不获得路径、SQLite、Node 或文件系统能力。
- 支持题干全文搜索以及年级、年份、题型、标签、月份和难度组合筛选，并提供分页和题目详情。
- 默认结果区完整显示且不自动选题；点击后，1264px 实机窗口使用左右布局，1050px 模拟窗口使用上下布局；详情可收起。
- 真实 380 MB 快照显示 25,370 道题、962 份试卷；题干、选项、本地图片、KaTeX 公式、答案和解析能够显示。
- 单题能作为独立 Markdown 副本导入素材库或有效课次；副本内嵌所需图片，不依赖之后的题库快照。服务测试同时验证了素材库和课次目标，真实快照 smoke 验证了素材库副本。
- 无效替换包会被拒绝，已有有效快照仍能继续搜索。
